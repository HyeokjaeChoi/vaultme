# VaultMe Local Runner

Development plugin for the Figma desktop app. The remote MCP cannot load Pretendard; this plugin runs in the desktop app, where local fonts load.
- Import once: Plugins → Development → Import plugin from manifest → this folder's `manifest.json`.
- Run: Plugins → Development → VaultMe Local Runner (or "Run last plugin").
- `code.js` is replaced per task. Each run writes `{task, out, error}` to `figma.root` shared plugin data `vaultme/log`; read it back with `use_figma` (`figma.root.getSharedPluginData('vaultme','log')`).
- PNG export: `tasks/export-pngs.js` (77 screens × Light/Dark = 154 PNGs; optional `ONLY` subset) posts 1x PNGs to `http://localhost:8765` (dev-only `devAllowedDomains` in `manifest.json`). Run a small receiver that writes the POST body to `work/v9/screens/<name>.png` first (2026-10-17, #54: scratchpad `recv.mjs`).
- Tasks: `tasks/fix-b1-text.js` (batch 1 phase B), `tasks/batch2-polish.js`, `tasks/batch2-critique.js`, `tasks/batch2-last.js` (backup of the previous code.js), `tasks/final-fixes.js` + `tasks/final-fixes-2.js` (final product review fixes, 2026-10-17: Light edits, Dark re-clone, repaint pass for stale bound paints). `tasks/seamless.js` (seamless-UX review follow-ups, 2026-10-17: spinner glyph, Copied variants, faucet row, S04–S06 states, S65 no-file state, first-launch sheet archived; run it with `const ONLY = [...]` prepended for a subset). `tasks/s05-cells.js` (S05 per-word cells + optional passphrase, 2026-10-17: B/Word cell, B/Input `Show action`, 3 Solar icons, S05 frames rebuilt in place of 423:15293, old frames archived; run with `const ONLY = ['onboarding']` prepended to rebuild only the frames). `tasks/final-review.js` (final app review Figma fixes, 2026-10-17; prepend `const MODE = ...`: fix, repaint, scan). `code.js` holds the last run task. Trigger: click the canvas, then cmd+option+P (Run last plugin). `tasks/visual-fixes.js` (aesthetic review fixes, S05/S06 decisions, Brand/Mark option A, 2026-10-17; run with `const ONLY = ['comps','face','mark','sweep','frames','s05s06','brand']` prepended, step by step). `tasks/audit-all.js` runs the audit in the plugin (async mainComponent) over all flow pages; the Desktop result can differ from the remote audit for `noticeClip` because Pretendard is loaded.

- 2026-10-17 re-review fixes (#54): `tasks/a11-*.js` are parts, not tasks. Build one task with `tasks/build.sh a11-common.js a11-frames-X.js` (writes `code.js` = prelude + files + tail; `PREPEND='const ONLY=["step"]; const NO_DARK=1'` runs a subset). `a11-components.js` (Product B/Link style, one neutral B/Status chip, B/Detail row Kind=Fact, B/Amount hero Kind=Confirmed), `a11-frames-a.js` (single chip, Ink amounts, Home dedupe, asset facts), `a11-frames-b.js` (review order, amount column, result hero, failed buttons), `a11-frames-c.js` (Tx facts, receive, S31 gate, start, settings, license), `a11-frames-d.js` (new S10B, S10B sheet, S30B), `a11-frames-e.js` (receive fact, annotations with Mobbin links), `a11-frames-f.js` (S63 wording, Activity test-mode chip). Light frames are edited, Dark twins are re-cloned (`PAIRS`), then a repaint pass runs. A `Chips` frame can also hold B/Chip selection chips: `chipsPass` filters by the `Chip ` instance name.
