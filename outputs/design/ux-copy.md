### 해결됨 (2026-10-13, [ux-terminology.md](ux-terminology.md) 기준)

- 해결: 전송 표현. "전송했어요"를 "보냈어요"로, 프레임 이름 "첫 송신"을 "첫 보내기"로 바꿨다.
- 해결: "Testnet 자산"을 "테스트넷 자산"으로 바꿨다. 영어 용어 나머지(passphrase, burn, chain)는 2026-10-13 적용했다. Etherscan·Ethereum은 유지.
- 해결: 프레임 이름 "유사 주소"를 화면 문구와 같은 "비슷한 주소"로 바꿨다.
- 해결: 상태 용어. 처리 중 / 블록에 포함됨 / 확정 / 실패 / 확인 못 함 / 대체됨으로 정했다. 화면은 이미 맞아서 바꾼 것이 없다.
