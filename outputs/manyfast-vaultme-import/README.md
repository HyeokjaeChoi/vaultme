# Manyfast VaultMe project import

Authenticated manyfast.io의 **다중 체인 셀프 커스터디 암호화폐 지갑 모바일 앱** 프로젝트에서 2026-10-05에 수집한 문서다.

## 파일

- `PRD.md` — PRD 본문
- `features/` — 현재 프로젝트에 존재하는 요구사항 6개와 각 수용 기준
- `user-flow/user-flow.md` — 유저플로우 섹션, 노드 라벨, 행동 라벨, Edge 목록
- `user-flow/user-flow.json` — 유저플로우 구조화 데이터
- `source-manifest.json` — 출처, 수집 방식, Export 제한 상태

## Export 상태

manyfast의 `내보내기` 메뉴는 현재 **내보내기 횟수를 모두 사용했어요** 상태였다. 기능명세서·유저플로우 Export 항목도 비활성화돼 있었다. 따라서 이 폴더는 로그인된 프로젝트 화면의 원문을 accessibility tree로 읽어 로컬 Markdown/JSON으로 보존한 결과다.

## 기능명세 범위

현재 기능 그래프에는 PRD → 요구사항 6개가 존재한다. `하위 전체 생성` 및 `Add children` 컨트롤은 있었지만 실제 생성된 하위 Feature 노드는 보이지 않았다. 존재하지 않는 상세 기능을 임의로 추가하지 않았다.
