# 01. 셀프 커스터디 지갑 생성 및 복구

- Manyfast ID: `R-BEXZTL`
- 상태: 기획 작성중

## 요구사항

사용자가 서버에 개인 키를 보관하지 않고 기기 내 안전한 영역에서 지갑을 생성하거나 기존 지갑을 시드 문구로 복구할 수 있어야 한다. 시드 문구는 생성·백업·검증·복구 절차로 관리하며, 앱은 시드 문구를 평문으로 서버에 전송하거나 저장하지 않아야 한다. 사용자가 지갑 생성 전에 자산 복구 책임과 분실 위험을 이해하도록 안내한다.

## 수용 기준

1. 신규 사용자는 지갑 생성 과정에서 시드 문구를 확인하고 순서 검증을 완료해야 다음 단계로 이동할 수 있다.
2. 시드 문구 백업 완료 여부와 복구 안내를 사용자에게 명확히 표시한다.
3. 기존 사용자는 유효한 시드 문구를 입력해 동일한 지갑 주소를 복구할 수 있다.
4. 시드 문구와 개인 키가 서버 로그, 분석 도구, 오류 보고서에 포함되지 않는다.
5. 앱 잠금, 생체 인증 또는 기기 인증을 통해 지갑 접근을 보호할 수 있다.
