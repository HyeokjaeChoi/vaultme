# 기능명세서

현재 manyfast 기능 그래프에서 확인된 항목은 **요구사항 6개**다. 그래프에는 PRD에서 6개 요구사항으로 가는 Edge만 있으며, 생성된 하위 Feature 노드는 보이지 않았다.

## 목록

- [01. 셀프 커스터디 지갑 생성 및 복구](./01-R-BEXZTL.md) — `R-BEXZTL` / 수용 기준 5개
- [02. 멀티체인 자산 잔액 및 통화 목록](./02-R-SLMSYW.md) — `R-SLMSYW` / 수용 기준 5개
- [03. 자산 송수신](./03-R-CMMQXK.md) — `R-CMMQXK` / 수용 기준 6개
- [04. 자산 변환](./04-R-XVLPFM.md) — `R-XVLPFM` / 수용 기준 6개
- [05. 거래 내역 및 상태 조회](./05-R-MOKBXD.md) — `R-MOKBXD` / 수용 기준 5개
- [06. 보안 경고 및 운영 관리](./06-R-WAJTMB.md) — `R-WAJTMB` / 수용 기준 6개

## 범위 메모

- Manyfast 화면에는 `하위 전체 생성` / `Add children` 컨트롤이 있었지만, 현재 저장된 프로젝트 상태에서는 하위 Feature 노드가 실제로 생성되어 있지 않았다.
- 따라서 이 폴더는 현재 프로젝트에 존재하는 기능명세서 내용을 모두 담되, 존재하지 않는 하위 명세를 임의로 생성하지 않는다.
