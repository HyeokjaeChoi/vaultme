# 04. 자산 변환

- Manyfast ID: `R-XVLPFM`
- 상태: 기획 작성중

## 요구사항

지원 가능한 변환 경로에 대해 사용자가 한 자산을 다른 자산으로 교환할 수 있도록 한다. 외부 변환 제공자 또는 유동성 공급자와 연동할 경우 견적, 환율, 수수료, 슬리피지, 최소 수령액, 거래 만료 시간을 사전에 표시하고 사용자가 직접 승인하도록 한다.

## 수용 기준

1. 사용자는 출발 자산·네트워크와 도착 자산·네트워크를 선택할 수 있다.
2. 견적 화면에 예상 환율, 네트워크 수수료, 서비스 수수료, 슬리피지, 최소 수령액이 표시된다.
3. 견적 만료 또는 가격 변동 시 재조회 후 최신 조건을 확인하게 한다.
4. 지원되지 않는 변환 경로, 유동성 부족, 잔액 부족 상황을 명확히 안내한다.
5. 변환 승인 전 사용자가 최종 거래 조건을 확인하고 서명해야 한다.
6. 변환 거래의 진행 상태와 완료 결과가 거래 내역에 기록된다.
