# 05. 거래 내역 및 상태 조회

- Manyfast ID: `R-MOKBXD`
- 상태: 기획 작성중

## 요구사항

체인별·자산별 송수신 및 변환 내역을 통합 제공한다. 거래 유형, 금액, 상대 주소, 수수료, 네트워크, 거래 상태, 요청 시각, 확정 시각과 블록 탐색기 링크를 표시해 사용자가 거래를 추적할 수 있도록 한다.

## 수용 기준

1. 사용자는 전체 거래 내역을 최신순으로 확인할 수 있다.
2. 체인, 자산, 거래 유형, 상태 기준으로 거래 내역을 필터링할 수 있다.
3. 각 거래에 대기, 처리 중, 완료, 실패 등 이해하기 쉬운 상태를 표시한다.
4. 거래 상세 화면에서 거래 식별자와 외부 블록 탐색기 링크를 확인할 수 있다.
5. RPC 또는 색인 서비스 지연 시 거래 상태가 확정되지 않았음을 명확히 표시하고 자동으로 갱신한다.
