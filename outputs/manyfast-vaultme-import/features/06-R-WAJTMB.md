# 06. 보안 경고 및 운영 관리

- Manyfast ID: `R-WAJTMB`
- 상태: 기획 작성중

## 요구사항

주소 오입력, 네트워크 불일치, 클립보드 붙여넣기, 고위험 거래, 시드 문구 노출 가능 상황을 감지하거나 경고한다. 관리자는 개인 키에 접근하지 않고 지원 네트워크·자산 목록, 공지, RPC 및 가격 제공자 상태를 운영할 수 있어야 한다.

## 수용 기준

1. 전송 전 네트워크 불일치, 비정상 주소, 수수료 부족, 큰 금액 거래에 대한 경고를 제공한다.
2. 시드 문구를 화면 캡처·복사·공유하지 않도록 안내하고 민감 화면의 보호 정책을 적용한다.
3. 루팅 또는 탈옥이 감지된 기기에서는 위험 안내와 제한 정책을 적용한다.
4. 관리자는 지원 네트워크와 자산의 활성화·비활성화 상태를 변경할 수 있다.
5. 관리자 기능은 개인 키, 시드 문구, 서명 데이터 원문에 접근할 수 없도록 권한을 분리한다.
6. 보안 이벤트, 거래 실패, 외부 연동 장애를 모니터링하고 감사 로그를 기록한다.
