## 파싱 메모

- manyfast 접근성 트리에서 Edge는 `n1`~`n72` 내부 ID로 노출됐고, 개별 화면 라벨은 별도 노드 텍스트로 노출됐다.
- 현재 접근성 출력은 내부 node ID와 화면 라벨의 1:1 매핑 속성을 함께 노출하지 않았다. 따라서 위 파일은 라벨 목록과 Edge ID 목록을 각각 원문 그대로 보존한다.
